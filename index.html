      Where does intent break down?

      Path analytics count what users did. They cannot tell a six-step journey from a six-step struggle. Jev judges each path's intent and each step's progress — cheap enough to run on every session, calibrated enough to average. What is left is the gap between what users wanted and what the interface afforded.
